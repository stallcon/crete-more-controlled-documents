Review extracted data

Each defined value is isolated from the original ticket, padded within its own column, enlarged, rendered several ways (contrast, adaptive black/white, negative, and decimal-specific when needed), then OCR results are compared. OCR remains suggestion-only: confirm against the source crop or enter the value manually. Moisture is shown as percent here and exported as a decimal fraction (0.50% → 0.005).

Each export uses a clean copy of your saved Ticket Importer.xlsx template. The Tickets sheet keeps row 1 headers, removes all prior ticket rows, writes only this queue starting at row 2, downloads the workbook, then clears the queue.
Export target: the workbook's Tickets sheet. Submittal SG, Weight/yd³, aggregate Absorption %, and Acceptable ±/yd³ reference columns are appended automatically to the right of the existing ticket columns. Moisture values are exported as decimal fractions (for example, 0.50% is written as 0.00500). The export is made self-contained: external workbook references are converted to internal sheet references where possible, external-link packages are removed, and Excel is forced to recalculate using only data and formulas inside the downloaded workbook.
